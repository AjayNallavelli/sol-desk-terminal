Phone alerts via ntfy (works when this page is closed)

A free GitHub Actions job in this repo checks new stonk.fun and Solana pairs about every 5 minutes (GitHub can delay scheduled runs) with the same rug checks and pump rule, and pushes at most 12 alerts an hour to an ntfy topic.
  1. Install the free ntfy app (Android / iOS) or open ntfy.sh in a browser.
  2. Tap + Subscribe to topic, server ntfy.sh, and enter the private topic name the desk gave you (it is deliberately not published here; anyone who knows it can read the alerts).
  3. Each alert: ticker + mcap with UTC time, why it passed, the mint on its own line, and buttons for this terminal, DexScreener, RugCheck and Jupiter.
Alerts are research pings, not trade calls. GitHub disables scheduled workflows after 60 days of repo inactivity; re-enable in the Actions tab.
